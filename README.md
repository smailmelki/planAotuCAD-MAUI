# PlanAotuCAD

تطبيق CAD ثنائي الأبعاد متعدد المنصات مبني باستخدام **C# و.NET MAUI**.

## الهدف المعماري

يعتمد المشروع على فصل مسؤوليات التطبيق حتى تبقى إضافة الأدوات والميزات ممكنة دون تضخيم صفحة الواجهة:

- **UI**: ملفات XAML وMainPage مسؤولة عن عرض الأدوات واستقبال أحداث المنصة.
- **Core/Models**: نماذج عناصر الرسم والمستند.
- **Core/Tools**: تعريف أدوات التحرير.
- **Core/Geometry**: تحويل الإحداثيات بين الشاشة ومساحة الرسم.
- **Core/Services**: تنفيذ عمليات التحرير وإدارة ملفات المستند.
- **Core/Drawing**: رسم المستند على GraphicsView فقط.

## الأدوات المتوفرة

- تحديد العنصر بالنقر عليه.
- تحريك العنصر المحدد بالسحب.
- حذف العنصر المحدد.
- رسم الخطوط والمستطيلات والدوائر.
- إدخال رقمي مستقل عن اللمس والماوس للخط (X/Y/Length/Angle) والمستطيل (X/Y/Width/Height) والدائرة (Center X/Center Y/Radius).
- تكبير وتصغير مساحة الرسم بعجلة الفأرة حول موضع المؤشر على Windows.
- تحريك مساحة الرسم: أداة التحريك (لمس أو ماوس) أو الزر الأوسط على Windows.
- تكبير مساحة الرسم بإيماءة القرص بإصبعين (Pinch) على الأجهزة اللمسية.
- تحريك مساحة الرسم بزر الفأرة الأوسط على Windows.
- حفظ المستند بصيغة JSON وفتحه من ملف JSON.
- استيراد وتصدير DXF الأساسي لعناصر LINE وCIRCLE وLWPOLYLINE؛ تُحوّل المستطيلات عند التصدير إلى أربعة خطوط.

## الواجهة المتكيفة (هاتف / كمبيوتر)

الصفحة الرئيسية واحدة وتستخدم عنصر رسم واحداً، لكن التخطيط يتبدل حسب حجم النافذة:
عرض ≥ 900 وارتفاع ≥ 520 ← تخطيط الكمبيوتر، وغير ذلك ← تخطيط الهاتف. (الهاتف في الوضع الأفقي يبقى بتخطيط الهاتف.)

**الهاتف: بسيط**
- مساحة الرسم تملأ الشاشة، وشريط سفلي بخمسة أزرار كبيرة: تحديد، تحريك، رسم، طبقات، المزيد.
- زر "رسم" يفتح صينية أشكال أفقية، ويعرض اسم الشكل الحالي؛ الضغط عليه من جديد يعيد فتح الصينية.
- الطبقات والخصائص في ورقة سفلية بدل القوائم المنبثقة. عند تحديد عنصر يظهر شريط صغير: خصائص / حذف.
- أداة "تحريك" بإصبع واحد، والقرص بإصبعين للتكبير، وزر عائم لملاءمة العرض.
- الإدخال الرقمي يقبل مسافة أو فاصلة بين الأرقام (دون الحاجة إلى ;) ويقبل الأرقام العربية.

**الكمبيوتر: احترافي**
- شريط قوائم أصلي (ملف، تحرير، رسم، عرض) مع اختصارات Ctrl+N/O/S/Z/Y/I/E/F.
- لوحة أدوات يسار، ولوحة يمين ثابتة للطبقات والخصائص، وشريط أوامر سريعة في الأعلى.
- شريط حالة: سطر أوامر، إحداثيات المؤشر، تبديل الالتقاط والشبكة، نسبة التكبير، عدد العناصر.
- سطر الأوامر: اكتب `L` خط، `R` مستطيل، `C` دائرة، `E` بيضاوي، `T` مثلث، `A` قوس،
  `P` متعدد الخطوط، `G` مضلع، `V` تحديد، `H` تحريك، ثم Enter. وأمر `DEL` و`U` و`REDO` و`FIT` و`GRID` و`SNAP` و`SAVE`.
  كتابة أرقام مباشرة (مثل `0 0 100 45`) تضيف عنصراً بالأداة الحالية.

**مشترك**
- الالتقاط بنقاط الشبكة (مفعّل افتراضياً)، وشبكة تتكيف مع التكبير وخطوط رئيسية كل أربعة.
- ملاءمة العرض بعد الفتح والاستيراد، ونطاق تكبير أوسع (0.01 – 100) للمخططات الكبيرة.
- قراءة حية للطول/الزاوية/الأبعاد أثناء الرسم.
- أول حفظ يسأل عن اسم المشروع؛ وهناك "حفظ باسم" و"مشروع جديد".

## مبدأ إضافة أداة جديدة

1. إنشاء نموذج جديد يرث من `CadEntity`.
2. تنفيذ `HitTest` و`Move` في النموذج.
3. إضافة نوع الأداة إلى `CadTool`.
4. إضافة إنشاء العنصر ومعاينته في `CadEditorService`.
5. إضافة طريقة رسم النموذج في `CadCanvasDrawable`.
6. إضافة سطر للأداة في مصفوفة `ToolDefs` داخل `MainPage.xaml.cs` (الاسم والأيقونة والتلميح والاختصارات)؛ يظهر زرها تلقائياً في لوحة الكمبيوتر وصينية الهاتف.

بهذا الترتيب تبقى هندسة العناصر مستقلة عن الواجهة وعن طريقة استقبال اللمس أو الماوس.

## البناء

من مجلد المشروع:

```powershell
dotnet restore
dotnet build -f net10.0-windows10.0.19041.0
```

ولأندرويد:

```powershell
dotnet build -f net10.0-android
```

> ملاحظة: الحفظ الحالي ينشئ ملفات JSON داخل مجلد بيانات التطبيق، بينما الفتح يسمح باختيار ملف JSON. يدعم DXF حالياً كيانات LINE وCIRCLE وLWPOLYLINE عند الاستيراد، ويصدر الخطوط والدوائر والمستطيلات (كمجموعة خطوط). الأقواس والمضلعات كعناصر أصلية، الإدخال الرقمي للأبعاد، الطبقات والتراجع/الإعادة مراحل تطوير تالية.
